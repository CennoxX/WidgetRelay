====================================================
Statement of changes (GPL-3.0 section 5a)
====================================================

The following changes were made to the original TaskerPluginSample project:

* 2026-07-13: The sample application in the `:app` module was removed and
  replaced with WidgetRelay, an entirely new application
  (package `com.cennoxx.widgetrelay`). All code under
  `app/src/main/java/com/cennoxx/` is original work and not derived from the
  upstream sample.

* 2026-07-13: `taskerpluginlibrary/build.gradle` - raised compileSdk from 34 to
  37, removed the deprecated `targetSdkVersion`, raised Java source/target
  compatibility from 17 to 21, and added `lint`, `testOptions` and
  `kotlinOptions` blocks.

* 2026-07-13: `taskerpluginlibrary/.../extensions/Public.kt` - replaced the
  deprecated `toLowerCase()` call with `lowercase()`.

* 2026-07-28: Removed upstream's Maven Central publishing setup
  (`scripts/publish-mavencentral.gradle` and the corresponding `apply from:`
  and `PUBLISH_*` properties in `taskerpluginlibrary/build.gradle`), as this
  fork consumes the library locally and does not republish it.

* 2026-07-28: Replaced upstream's README.md with documentation for WidgetRelay
  and removed the `projectFilesBackup/` directory.

No other files in the `taskerpluginlibrary` module have been modified.
